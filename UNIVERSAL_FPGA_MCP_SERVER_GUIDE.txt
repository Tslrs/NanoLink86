1. EXECUTIVE SUMMARY & CONCEPT
================================================================================
Traditionally, FPGA developers working on modern MacBooks (especially Apple Silicon
M1/M2/M3/M4) face a huge bottleneck:
- Proprietary FPGA tools (like Xilinx ISE 14.7 / iMPACT) require huge virtual machines
  (20-30 GB Linux x86 VMs).
- Proprietary programmers (like the Xilinx Platform Cable USB DLC9G/DLC10) fail to
  work across VM USB passthrough because of proprietary kernel drivers.

THE MCP SOLUTION:
By building a lightweight "Universal FPGA MCP Server" (Model Context Protocol),
any AI Agent or developer can command JTAG operations natively on macOS:
- Detect connected FPGA boards (Tang Nano, Spartan-3A, Spartan-6, ECP5, ICE40).
- Program FPGA SRAM (`.bit`, `.fs`, `.bin`) instantly.
- Program permanent on-board SPI Flash (`.mcs`, `.bin`).
- Patch BRAM (BIOS / software) in 1 second without re-synthesis.
- Run hardware-in-the-loop tests directly from natural language.

2. WHY SPARTAN-3A PROGRAMMING FAILED ON MAC (THE ROOT CAUSE)
================================================================================
Why could you not program the Spartan-3A directly on Mac with the official programmer?

1. The Cypress FX2 Renumeration Problem:
   The official Xilinx Platform Cable USB (and the on-board USB port of the
   Spartan-3A Starter Kit) uses a Cypress EZ-USB FX2 microcontroller (CY7C68013A).
   When plugged in, it powers up in an unconfigured state (VID 0x04b4 / 0x03fd).
   The Xilinx driver must upload closed-source firmware (`xusbdfwu.hex`) via USB
   RAM using `fxload`. Once loaded, the device disconnects and reconnects as a
   different USB device (VID 0x03fd PID 0x0008).
   In macOS virtual machines (UTM, VirtualBox, VMware), this dynamic USB disconnect/
   reconnect causes the VM to lose the USB handle 90% of the time!

2. Closed-Source Kernel Drivers (`windrvr6`):
   Xilinx iMPACT relies on Jungo WinDriver or proprietary Linux kernel modules
   compiled strictly for x86 Linux 2.6/3.x. Apple Silicon Macs cannot run x86 kernel
   extensions.

3. Result: Developers were trapped inside huge Ubuntu 14.04 VMs battling USB errors!

================================================================================
3. THE MODERN SOLUTION: NATIVE MACOS HARDWARE PROGRAMMING (ZERO-VM)
================================================================================
We do NOT need Xilinx iMPACT or proprietary drivers to program the Spartan-3A!

Using modern open-source JTAG engines:
1. `openFPGALoader`:
   - Ultra-fast, lightweight (~2 MB), written in C++.
   - Already installed natively on macOS via Homebrew (`/opt/homebrew/bin/openFPGALoader`)!
   - Communicates directly via standard user-space `libusb` and `libftdi` (NO kernel drivers!).
   - Supports: Gowin (Tang Nano 9K/4K/20K), Xilinx (Spartan-3, Spartan-3A, Spartan-6, 7-series),
     Lattice (ECP5, iCE40), Intel/Altera (Cyclone).

2. `xc3sprog`:
   - Specifically built for Xilinx Spartan-2, Spartan-3, Spartan-3A, Spartan-6.
   - Compiles natively on macOS with `clang`.
   - Supports writing directly to the Atmel AT45DB161D SPI flash of the Spartan-3A.

4. UNIVERSAL HARDWARE PROGRAMMER OPTIONS (FOR ALL BOARDS)
================================================================================
Instead of the problematic Xilinx Platform Cable, you can use any of these open,
native USB-JTAG adapters that work seamlessly on macOS:

Option A: FTDI FT2232H / FT232H USB-to-JTAG Adapter (Cost: 5 - 12 EUR)
- Hardware: "CJMCU-2232" or "Adafruit FT232H" or "Digilent JTAG-HS2 / HS3".
- Plug-and-play on macOS (native FTDI driver in macOS).
- Pins to Spartan-3A JTAG header (J1):
    FTDI Pin       Spartan-3A JTAG Header (6-pin / 14-pin)
    ------------------------------------------------------
    TCK   --------> TCK
    TDI   --------> TDI
    TDO   <-------- TDO
    TMS   --------> TMS
    GND   --------> GND
    VCCIO --------> VCC (3.3V sense)

Option B: Raspberry Pi Pico ($4) running "DirtyJTAG"
- Turn a $4 Raspberry Pi Pico into a high-speed USB JTAG programmer!
- Flash the `dirtyJtag.uf2` firmware onto the Pico (drag & drop).
- Plug into Mac USB -> `openFPGALoader -c dirtyJtag -b spartan3a ...`
- 100% native on Mac, zero drivers required.

Option C: Tang Nano 9K On-Board Programmer (BL702 / FT2232)
- Built-in on the Tang Nano board. Plug the USB-C cable into the Mac.
- `openFPGALoader -b tangnano9k bitstream.fs` programs it instantly!

5. MCP SERVER ARCHITECTURE FOR HARDWARE & FPGA CONTROL
================================================================================
The Model Context Protocol (MCP) allows an AI agent (Claude, Antigravity, etc.)
to act as an intelligent hardware engineer:

     +-------------------------------------------------------+
     |         LLM / AI Assistant (Claude, Antigravity)      |
     +-------------------------------------------------------+
                               |
                   MCP Protocol (JSON-RPC)
                               |
                               v
     +-------------------------------------------------------+
     |             Universal FPGA MCP Server                 |
     |              (`fpga_mcp_server.py`)                   |
     +-------------------------------------------------------+
             |                 |                 |
             v                 v                 v
     [openFPGALoader]      [xc3sprog]       [esptool.py]
             |                 |                 |
     +-----------------+---------------+-----------------+
     |                 |               |                 |
     v                 v               v                 v
 Tang Nano 9K      Spartan-3A      Spartan-6           ESP32
 (Gowin FPGA)    (Xilinx FPGA)   (Xilinx FPGA)    (Microcontroller)

Exposed MCP Tools:
1. `detect_hardware`: Scans USB bus for connected FPGA boards and JTAG chains.
2. `program_sram`: Writes bitstream directly to FPGA volatile memory (fast test).
3. `program_flash`: Writes bitstream to non-volatile SPI flash (permanent cold-boot).
4. `patch_bram`: Patches memory bytes directly in a `.bit` file in 1 second.
5. `flash_esp32`: Uploads MicroPython or C firmware to the ESP32 wireless gateway.
6. `read_serial`: Reads live UART telemetry from the board.

6. COMPLETE IMPLEMENTATION: `fpga_mcp_server.py`
================================================================================
Save this script as `/Users/nt/Documents/NANO/web_dos/tools/fpga_mcp_server.py`:

```python
#!/usr/bin/env python3
"""
Universal FPGA & Hardware MCP Server
Supports: Tang Nano 9K, Xilinx Spartan-3A, Spartan-6, ESP32, Lattice
Author: Nikolaos Tsalaris (Tslrs)
"""

import sys
import subprocess
import shutil
import json
from pathlib import Path
from mcp.server.fastmcp import FastMCP

# Initialize FastMCP Server
mcp = FastMCP("Universal-FPGA-Server")

OPENFPGA = shutil.which("openFPGALoader") or "/opt/homebrew/bin/openFPGALoader"
ESPTOOL = shutil.which("esptool.py") or "esptool.py"

@mcp.tool()
def detect_hardware() -> str:
    """Scans USB and JTAG chain for connected FPGA boards and debuggers."""
    results = []
    
    # Check openFPGALoader detection
    try:
        proc = subprocess.run([OPENFPGA, "--detect"], capture_output=True, text=True, timeout=5)
        results.append("=== JTAG Detection (openFPGALoader) ===")
        results.append(proc.stdout if proc.stdout else proc.stderr)
    except Exception as e:
        results.append(f"JTAG detection failed: {e}")
        
    # Check USB devices on macOS
    try:
        proc = subprocess.run(["system_profiler", "SPUSBDataType"], capture_output=True, text=True, timeout=5)
        lines = [line.strip() for line in proc.stdout.splitlines() if any(k in line.lower() for k in ["ftdi", "gowin", "xilinx", "ch55", "cp210", "ch34"])]
        results.append("\n=== Connected Hardware USB Interfaces ===")
        results.append("\n".join(lines) if lines else "No known FPGA USB bridges detected.")
    except Exception as e:
        results.append(f"USB profiler error: {e}")
        
    return "\n".join(results)

@mcp.tool()
def program_sram(board: str, bitstream_path: str, cable: str = "") -> str:
    """
    Programs an FPGA SRAM (volatile, immediate execution).
    board: 'tangnano9k', 'spartan3a', 'spartan6', etc.
    bitstream_path: Path to the .bit or .fs file.
    cable: Optional cable name (e.g., 'ft2232', 'dirtyJtag', 'digilent_hs2').
    """
    p = Path(bitstream_path)
    if not p.is_file():
        return f"Error: Bitstream file '{bitstream_path}' not found."

    cmd = [OPENFPGA, "-m"]
    if board:
        cmd.extend(["-b", board])
    if cable:
        cmd.extend(["-c", cable])
    cmd.append(str(p.resolve()))

    try:
        proc = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        if proc.returncode == 0:
            return f"SUCCESS: SRAM programmed successfully!\n{proc.stdout}"
        else:
            return f"FAILED (code {proc.returncode}):\nStdout: {proc.stdout}\nStderr: {proc.stderr}"
    except Exception as e:
        return f"Execution error: {e}"

@mcp.tool()
def program_flash(board: str, bitstream_path: str, cable: str = "") -> str:
    """
    Programs an FPGA on-board SPI Flash (non-volatile, permanent cold boot).
    """
    p = Path(bitstream_path)
    if not p.is_file():
        return f"Error: Bitstream file '{bitstream_path}' not found."

    cmd = [OPENFPGA, "-f"]
    if board:
        cmd.extend(["-b", board])
    if cable:
        cmd.extend(["-c", cable])
    cmd.append(str(p.resolve()))

    try:
        proc = subprocess.run(cmd, capture_output=True, text=True, timeout=120)
        if proc.returncode == 0:
            return f"SUCCESS: SPI Flash programmed permanently!\n{proc.stdout}"
        else:
            return f"FAILED (code {proc.returncode}):\nStdout: {proc.stdout}\nStderr: {proc.stderr}"
    except Exception as e:
        return f"Execution error: {e}"

@mcp.tool()
def flash_esp32(port: str, firmware_path: str, baud: int = 460800) -> str:
    """
    Flashes ESP32 gateway firmware via esptool.py.
    """
    p = Path(firmware_path)
    if not p.is_file():
        return f"Error: Firmware file '{firmware_path}' not found."

    cmd = [ESPTOOL, "-p", port, "-b", str(baud), "write_flash", "0x10000", str(p.resolve())]
    try:
        proc = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        return proc.stdout if proc.returncode == 0 else f"Failed:\n{proc.stderr}"
    except Exception as e:
        return f"Execution error: {e}"

if __name__ == "__main__":
    mcp.run()
```

7. STEP-BY-STEP MACOS SETUP & INSTALLATION
================================================================================

Step 1: Install prerequisite packages on macOS (via Homebrew)
Open macOS Terminal and run:
```bash
# openFPGALoader is already installed!

```

Step 2: Verify `openFPGALoader` detects your hardware
Plug in your FPGA board (or JTAG cable) to your Mac USB and test:
```bash
# Detect connected FPGA / JTAG Chain:
openFPGALoader --detect

# Example: Program Tang Nano 9K:
openFPGALoader -b tangnano9k /path/to/project.fs

# Example: Program Spartan-3A via FTDI cable:
openFPGALoader -c ft2232 /path/to/next186_spartan3a_freedos.bit
```
